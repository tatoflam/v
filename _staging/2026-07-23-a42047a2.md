## 2. OpenSpec change `support-new-milestone-sheet-format` 起票 + 実装

起票時に live read-only 実測で判明した重要事実 3 点:

1. **実シート名は `"Milestone "`（末尾スペース付き）** — config の `"Milestone"`
   と不一致で、放置すると翌朝 9:00 の daily pipeline から Milestone 取得が失敗
   （非致命 warning で縮退）。config 更新を tasks 最優先（1.1）に配置
2. 行 2 に旧タイトル行が残存するが、ヘッダ検出は「process_name 一致最多の行」
   方式なので config の process_name を新タイトルへ置換すれば行 3 が確実に勝つ
   （検出コード変更不要）
3. 行 3 にタイトルの無い列が 4 つ（躯体形状 / 施工図作成依頼 等）。
   Milestone 末尾のブランク列はユーザーがスプシ側で除外して config と整合

ユーザー決定: 提示方針を承認（2, 3 とも「その方向で OK」）。`/opsx:apply` で実装
（change ディレクトリは現時点で未 commit、archive 待ち）。
